# Secure Banking DevOps Pipeline

## Project Overview
This project demonstrates a secure CI/CD pipeline for a simulated banking transaction application using GitHub, Jenkins, Selenium, Docker, Kubernetes, Prometheus, and Grafana.

## Objectives
- Develop a simulated banking transaction application.
- Automate testing using Pytest and Selenium.
- Build and package the application using Docker.
- Automate CI/CD using Jenkins.
- Deploy the application to Kubernetes.
- Monitor application health and metrics using Prometheus and Grafana.
- Apply security best practices throughout the pipeline.

## Technology Stack
- Python and Flask
- Pytest and Selenium
- Git and GitHub
- Jenkins
- Docker
- Kubernetes and Minikube
- Prometheus and Grafana

## Disclaimer
This is an educational demonstration using simulated banking data. It is not intended for real banking transactions.
